# AUDIO-HARNESS 最小原型验证实验方案

**项目全称**：无损听觉记忆与主动回放框架在长音频推理中的有效性验证  
**项目定位**：整个听觉 Harness 研究路线的**决定性第一步实验**——仅验证核心假设（无损记忆+主动回放），暂不引入慢放、分轨、蒸馏等扩展能力，用最小成本验证范式是否成立，为后续投入提供决策依据  
**对标范式**：VISTA (Han et al., 2026, MIT) 视觉 Harness 框架的听觉领域迁移

---

## 一、研究背景与核心假设

### 1.1 待解决的问题

当前音频大模型普遍遵循「一次性编码 + 固定上下文窗口」范式，存在三个本质缺陷：

1. **预判偏差**：首次编码时无法预知后续推理需要哪些声学细节，压缩编码可能丢失关键信息
2. **上下文溢出**：超出原生长度限制后，早期片段被截断或被文本摘要替代，原始声学信息不可逆丢失
3. **粒度固化**：编码分辨率固定，无法针对特定片段动态提升时间/频率分辨率

### 1.2 核心假设

> 
> **无需微调基础音频模型，仅通过外部 Harness 层提供无损原始音频记忆与模型自主的主动回放工具，即可显著提升长音频场景下的推理准确率；且长度越长、推理越细，增益越显著。**

### 1.3 对标逻辑

与 VISTA 在视觉领域的验证逻辑一一对应：

- VISTA：原始图像无损存储 → 模型按需回看/放大 → 解决编码丢失细节、历史画面溢出问题
- AUDIO-HARNESS：原始音频无损存储 → 模型按需回放/重听 → 解决编码丢失细节、历史音频溢出问题

## 二、实验目标

### 2.1 主要目标

在公开标准基准上，量化「无损音频记忆 + 主动回放」相对于主流长音频处理方案的性能提升幅度，验证 Harness 范式在听觉领域的有效性。

### 2.2 次要目标

1. 分析**音频长度**与性能增益的关系：短/中/长三档音频下的增益差异
2. 分析**任务类型**与性能增益的关系：哪类推理任务从回放中受益最大
3. 量化 Harness 带来的 token 开销与推理延迟，评估效率代价
4. 统计模型的工具调用行为，理解模型如何使用回放能力

## 三、选型：基础模型与测试基准

### 3.1 基础模型：Audio Flamingo 3 (AF3)

**选型结论**：优先选用 Audio Flamingo 3，作为当前开源长音频领域的公认标杆。

| 参数项 | 规格说明 |
| --- | --- |
| 总参数量 | ~8.3B（Qwen-2.5-7B 语言骨干 + 音频编码器） |
| 原生最大音频长度 | **10 分钟硬限制**（30秒窗口 × 20 个窗口化池化） |
| 文本上下文窗口 | 32.8K tokens |
| 显存占用（BF16） | ~16 GB |
| 显存占用（4bit 量化） | ~8–10 GB |
| 核心优势 | 1. 专门针对长音频优化训练，开源领域长音频 SOTA   2. 原生支持多轮对话与 on-demand 思维链，与工具调用模式天然契合   3. 训练数据最长 10 分钟，10 分钟以上数据分布外，实验结果真实   4. 学术认可度高，结果可直接与业界 SOTA 对比 |

### 3.2 测试基准：ChronosAudio

**选型结论**：采用 ChronosAudio 公开标准基准，替代自制测试集，保障学术认可度与可复现性。

| 参数项 | 规格说明 |
| --- | --- |
| 数据规模 | 6000 条独立音频，36000 个测试实例 |
| 长度分层 | **短音频**：30秒–5分钟（3000条）   **中音频**：5–10分钟（2000条）   **长音频**：10–20分钟（1000条） |
| 任务类型 | 1. 事实检索 2. 时序推理 3. 多跳推理   4. 总结概括 5. 说话人识别 6. 情感判断 |
| 核心优势 | 1. 官方提供 16 个主流模型的基线成绩，结果可直接横向对比   2. 长度梯度完美覆盖 AF3 的 10 分钟临界值，可验证「限内提升」与「突破限制」两层结论   3. 标准评测脚本与指标定义，结果可复现 |

### 3.3 备选方案

- **模型备选**：若显存不足（≤12GB），降级使用 Qwen2-Audio-7B-Instruct，但需在结论中说明模型基线偏低的影响
- **基准备选**：补充 AudioMarathon（侧重中长音频推理效率）、LAT-Bench（侧重时间定位精度）做交叉验证

## 四、实验设计

### 4.1 实验配置（2 条基线 + 1 组实验组）

所有配置使用**同一个基础模型（AF3）**、**同一个测试集（ChronosAudio）**、**同一套评测指标**。

| 配置编号 | 方案描述 | 对应业界常规做法 | 实验作用 |
| --- | --- | --- | --- |
| **B1 原生基线** | ≤10 分钟音频完整直接输入；>10 分钟截断前 10 分钟输入 | 模型原生能力上限 | 基准参考线 |
| **B2 分段摘要基线** | 音频按 30 秒分段，每段生成文本摘要，用摘要串联推理 | 业界最常用的长音频处理方案 | 核心对比组，验证「无损波形记忆」优于「文本摘要记忆」 |
| **H1 实验组** | 音频按 30 秒分段输入 + 无损音频记忆库 + 模型自主调用 `inspect` 回放工具 | 本研究提出的 Harness 方案 | 验证核心假设 |

### 4.2 变量控制

- **唯一变量**：历史信息的承载形式 —— 原生压缩编码 / 文本摘要 / 无损原始波形 + 主动回放
- **控制变量**：基础模型、测试集、评测指标、总 token 预算上限、单题推理时间上限

### 4.3 分层验证逻辑

通过短/中/长三档音频的结果对比，分层验证两个结论：

1. **10 分钟以内（原生可处理范围）**：验证「即使音频能全部塞进上下文，无损记忆+主动回放依然能提升推理精度」——对应 VISTA「图像全可见，但放大回看依然有用」
2. **10–20 分钟（原生超出范围）**：验证「超出原生长度限制后，Harness 能突破模型物理长度限制」——对应 VISTA「长交互中记忆不溢出」

## 五、核心组件详细实现

### 5.1 无损音频记忆库

- **存储内容**：所有分段原始音频，采用 FLAC 无损压缩格式存储，信息零损失
- **索引机制**：双层索引 —— 分段 ID + 毫秒级时间戳，支持任意时间区间精确寻址
- **生命周期**：与任务绑定，全程独立存储，不受模型上下文窗口重置影响
- **设计原则**：只存不读，模型不调用时不占用上下文空间；调用时才提取编码送入上下文

### 5.2 inspect 主动回放工具

**工具接口定义（向模型暴露）**：

```
def inspect(start_time: float, end_time: float) -> None:
    """
    回放指定时间段的原始音频，重新编码送入当前对话上下文。
    
    Args:
        start_time: 回放起始时间，单位秒
        end_time: 回放结束时间，单位秒
    """
```

**执行逻辑**：

1. 接收模型的工具调用请求与时间参数
2. 根据时间戳从记忆库中提取对应音频片段（跨分段自动拼接）
3. 将原始音频重新输入 AF3 音频编码器
4. 编码结果拼接到当前对话上下文，供模型继续推理

### 5.3 双笔记状态机制（简化版）

完全对标 VISTA 的双文件设计，用于上下文重置时的状态延续：

- `WORKING.md`：记录当前已提取的关键信息、待确认问题、推理进度
- 上下文接近 28K token 时，模型生成精简交接摘要写入 `WORKING.md`，重置上下文后继续推理
- 原始音频记忆库全程保留，不受上下文重置影响

### 5.4 端到端运行流水线

```
音频分段输入 → 模型接收当前片段 → 更新推理状态
       ↓
信息不足？→ 调用 inspect 工具 → 提取原始音频重编码 → 修正推理
       ↓
生成中间答案 / 最终答案
       ↓
上下文接近上限 → 写入 WORKING.md → 重置上下文 → 继续
```

## 六、评测指标体系

全部沿用 ChronosAudio 官方指标定义，确保与基线可比。

### 6.1 核心性能指标

- **客观题**：准确率（Accuracy）、F1 值
- **主观题（摘要）**：ROUGE-L、BERTScore

### 6.2 分层分析指标

1. **分长度准确率**：短/中/长三档音频分别统计，绘制性能衰减曲线
2. **分任务准确率**：6 类任务分别统计，识别增益最大的任务类型
3. **分位置准确率**：按答案在音频的前/中/后段分别统计，验证记忆溢出效应

### 6.3 效率与开销指标

- 平均每题总 token 开销
- 平均每题推理时间
- 平均每题工具调用次数
- 工具调用的时间分布（集中在哪些推理阶段）

## 九、成功判据与决策标准

### 9.1 核心假设通过标准

满足以下两条即可判定**核心假设成立**，Harness 范式在音频领域有效：

1. **整体提升**：全量测试集上，H1 相比 B2（分段摘要基线）准确率提升 **≥ 5%**
2. **长程效果**：10–20 分钟长音频上，H1 相比 B1（原生截断基线）准确率提升 **≥ 10%**

### 9.2 增益预期参考

| 音频长度 | 预期提升幅度（H1 vs B2） | 意义 |
| --- | --- | --- |
| 短音频（<5分钟） | +2% ~ +4% | 全量输入下回放仍有边际增益 |
| 中音频（5–10分钟） | +5% ~ +8% | 接近上下文极限时无损记忆开始显著发挥作用 |
| 长音频（10–20分钟） | +15% ~ +25% | 突破原生长度限制，增益巨大 |
| **整体加权** | **+8% ~ +12%** | 核心结论成立 |

### 9.3 后续决策路径

- ✅ **验证通过**：进入下一阶段，扩展慢放工具、分轨工具，完成完整消融实验
- ⚠️ **增益微弱（3%–5%）**：分析错误类型，转向聚焦细粒度推理场景（如语音细节、音乐结构）
- ❌ **验证不通过（<3%）**：及时止损，放弃 Harness 路线，转向其他研究方向

## 十、风险与应对

| 风险项 | 概率 | 影响 | 应对策略 |
| --- | --- | --- | --- |
| 模型几乎不调用回放工具 | 中 | 高 | 1. 在系统提示中强化「不确定就回放」的引导   2. 增加强制回放对照组，验证「回放本身有用」与「模型会不会用」是两个问题 |
| 官方基线复现偏差大 | 低 | 中 | 严格对齐官方评测配置（采样率、提示词、推理参数） |
| 长音频推理时间过长 | 中 | 低 | 设置单题时间上限，超时按错误处理，统计时单独标注 |
| 增益主要来自「多听了几遍」而非「无损记忆」 | 中 | 中 | 增加对照实验：固定次数重复播放 vs 模型自主选择回放，分离两者贡献 |

## 十一、验证通过后的扩展方向

1. **工具扩展**：加入 `slow_down`（慢放）、`separate_track`（分轨）、`read_samples`（读采样值）三类细粒度工具
2. **完整消融**：递进式组件消融，量化每个组件的边际贡献
3. **多基准验证**：扩展到 SpeechWorld（交互任务）、STAR-Bench（细粒度推理）
4. **知识蒸馏**：用大模型+Harness 的推理轨迹蒸馏小模型，探索效率优化路径
